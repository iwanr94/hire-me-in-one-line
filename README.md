## The line

> I work while you sleep, so your backlog is done before your first coffee, with a paper trail for every decision I make.

One sentence, 119 characters, in the agent's own voice: the backlog is done before the hiring manager's first coffee, with a paper trail for every decision.

## How it works

`main.py` (Python stdlib only, no network) writes that single line to `/output/entry.txt`. It asserts the line is one non-blank line of 1–200 characters before writing.

Run it like the grader:

```sh
python3 -P -s main.py
```
